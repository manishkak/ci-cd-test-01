### **3️⃣ Tag your local Docker image for Docker Hub**

Your image right now is named **backend-app:latest** (local only).

We need to tag it for pushing:

```
docker tag backend-app:latest <your-dockerhub-username>/backend-app:latest
```

Example:

```
docker tag backend-app:latest manish010/backend-app:latest
```

-> After this run: docker images
You should now see something like:
REPOSITORY                    TAG       IMAGE ID       CREATED         SIZE
backend-app                   latest    c965d401a679   3 days ago      548MB
manishkak/backend-app         latest    c965d401a679   3 days ago      548MB

Notice both entries have the same IMAGE ID → that confirms it's just a new tag.

Also, Check in Docker Desktop

Open Docker Desktop → Images tab
You should now see two entries:
backend-app:latest
manish010/backend-app:latest

Same size & same image ID.

### **4️⃣ Login to Docker Hub using CLI**

You do this once on your machine:

```
docker login
```

Enter your Docker Hub username + password.

---

### **5️⃣ Push the image**

Push your tagged image to Docker Hub:

```
docker push manishkak/backend-app:latest
```

This will upload your Docker image so Azure can use it.

-> On Docker hub now you should be able to see your image with the tag- backend-app:latest
Perfect — Docker image is now on Docker Hub, which means your backend is fully containerized and publicly pullable. (Do only till here and move to the next document. You can just read what comes next below)
---

### **6️⃣ Deploy backend container to Azure Web App (for Containers)**

This is the part where your Docker container becomes an actual deployed backend.

Steps (we will do one by one later):

1. Go to Azure Portal
2. Create a **Web App**
3. Choose:

   * **Publish: Docker container**
   * **OS: Linux**
4. In “Container Settings”, set:

   * Registry: Docker Hub
   * Image: `<username>/backend-app`
   * Tag: `latest`
5. Finish deployment
6. Web App will auto-pull your image and run it
7. You get a public URL like:
   `https://backend-app.azurewebsites.net/`
