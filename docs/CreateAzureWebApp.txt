# ✅ **NEXT STEPS (where we go from here)**

Now that your image is pushed to Docker Hub, here’s the roadmap:

---

## **5️⃣ Test pulling your image (optional but recommended)**

Just to confirm everything is good, you can pull the image on *any* machine.

Run this in VS Code terminal (Git Bash or PowerShell — both fine):

```bash
docker pull manish010/backend-app:latest
```

You should see it download without errors.

---

## **6️⃣ Create an Azure Web App for Containers**

We will deploy this Docker image on Azure.

### **Step A — Login to Azure**

```bash
az login
```

A browser window will open → log in.

---

### **Step B — Create a Resource Group**

```bash
az group create --name phpDockerRG --location eastus
```

---

### **Step C — Create an App Service Plan**

(Needed for the Web App to run containers)

```bash
az appservice plan create --name phpDockerPlan --resource-group phpDockerRG --is-linux --sku B1
```

---

### **Step D — Create the Web App (Container)**

```bash
az webapp create \
    --resource-group phpDockerRG \
    --plan phpDockerPlan \
    --name php-docker-backend-001 \
    --deployment-container-image-name manish010/backend-app:latest
```

This creates a live URL like:

```
https://php-docker-backend-001.azurewebsites.net
```

---

## **7️⃣ Configure Azure to auto-pull new Docker images on update**

Azure does NOT automatically pull latest tags unless told.

Run:

```bash
az webapp config container set \
    --name php-docker-backend-001 \
    --resource-group phpDockerRG \
    --docker-custom-image-name manish010/backend-app:latest \
    --docker-registry-server-url https://index.docker.io/v1/
```

---

## **8️⃣ Restart the Web App**

```bash
az webapp restart \
    --name php-docker-backend-001 \
    --resource-group phpDockerRG
```
